## 📌 모아코(MOAKO)  
**모아코**는 게임 *로스트아크* 의 주요 재화인 **골드**를 체계적으로 관리할 수 있는 **골드 가계부 웹 서비스**입니다.  
최근 *로스트아크* 에서 골드 획득 및 소비 기회가 더욱 다양해지면서, 많은 유저들이 이전보다 더 많은 골드를 보유하고 사용하게 되었습니다.  
이로인해 방대해진 골드의 흐름을 한눈에 파악하기 어려워, **수입과 지출을 효율적으로 관리할 필요성**이 커졌기에 **프론트엔드** 기술만을 이용하여 개발하게 되었습니다. 

---

## 🛠 사용된 기술  
### **프론트엔드**
- **프레임워크:** React, React Router  
- **상태 관리:** useState, useEffect, LocalStorage  
- **API 통신:** Fetch API  
- **로컬 저장소:** AsyncStorage  
- **UI 스타일링:** Tailwind CSS  
- **차트 라이브러리:** Recharts  

### **배운 점 & 적용 기술**
> - React를 활용한 상태 관리 및 데이터 로컬 저장 적용  
> - Tailwind CSS를 활용한 UI/UX 개선  
> - Recharts를 활용한 통계 차트 구현  
> - React Router를 활용한 페이지 전환
